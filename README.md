## Featured projects

### [OpenArc](https://github.com/raunak-dows17/openarc)
A local-first AI agent designed to run on your machine by default. OpenArc combines local Ollama models with web search, source-grounded answers, persistent memory, and a terminal workspace. It can manage sessions, scheduled jobs, skills, and tools, with explicit approvals for sensitive actions. The project reflects my interest in private, evidence-based AI that can do more than chat.

**Focus:** TypeScript · Ollama · Agent tools · RAG and memory · Web grounding · CLI/TUI

### [ARC — Autonomous Regenerative Companion](https://github.com/raunak-dows17/arc)
A cross-platform AI companion and agent that supports local, hybrid, or cloud model setups. ARC routes tasks to suitable models, supports profiles, skills, memory, and bounded sub-agents, and provides tools for research and coding. Its design emphasizes clear privacy boundaries and human approval for actions that affect files or use external services.

**Focus:** TypeScript · AI agents · Model orchestration · Ollama and cloud providers · Sub-agents · Safety boundaries

### [Koalatale](https://github.com/raunak-dows17/koalatale)
A collaborative storytelling platform for writers and readers. People can share stories, contribute ideas or passages, and let an author choose which contributions become part of the story. I like this project’s community-driven approach to creative writing: readers can take part in shaping a story while the author retains editorial control.

**Focus:** Flutter · Dart · Cross-platform app development · Collaborative writing

### [Sayin Chat App](https://github.com/raunak-dows17/Realtime-Chat-Application)
A real-time messaging application built with the MERN stack. Users can sign up, find other users, and chat; they can also create group conversations. Group creators act as admins and can manage members and the group name, while other participants join as members.

**Focus:** MongoDB · Express.js · React · Node.js · Real-time chat · Group management
